```text live/venue
warning: pass sandbox: to createVendo (e.g. sandbox: e2bSandbox(), which
reads E2B_API_KEY as its credential), or set VENDO_API_KEY for the managed
Cloud sandbox; without one, server apps (rungs 2-4) return sandbox-unavailable
```

`check: live/venue` · `error_code: E-LIVE-004` · `doctor exits: 0`

## What you're seeing

A warning, not a failure. `/status` reports no execution venue at all.

## Why

The composition has no sandbox adapter. Tree-only apps still render fine,
but any user app that needs a server, rungs 2 through 4, answers
`sandbox-unavailable`.

## The fix

Set `VENDO_API_KEY` and Vendo fills the sandbox slot with the managed Cloud
sandbox automatically, no `sandbox` option needed.

```bash
export VENDO_API_KEY=vnd_live_...
```

Restart the dev server and re-run `npx vendo doctor`; `blocks.sandbox`
should now report `cloud`.
