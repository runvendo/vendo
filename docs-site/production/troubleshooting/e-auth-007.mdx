```text auth/act-as
warning: actAs is not configured; pass createVendo({ actAs }) before
enabling away host actions
```

`check: auth/act-as` · `error_code: E-AUTH-007` · `doctor exits: 0`

## What you're seeing

A warning: the composition has neither an `auth` preset nor a hand-wired
`actAs` seam.

## Why

Present (user-in-the-room) calls work fine without it. Away calls, where the
agent acts through your host API while the user is not at a browser, have no
credential to use.

## The fix

Wire an auth preset; most presets fill `actAs` for you.

```ts vendo/server.ts
import { authJs } from "@vendoai/vendo/auth/auth-js";
import { createVendo } from "@vendoai/vendo/server";

export const vendo = createVendo({ auth: authJs() });
```

Or pass `createVendo({ actAs })` directly before enabling away host actions.
Leaving this unset is fine for a present-only install; it never blocks
doctor.
