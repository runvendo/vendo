`check: auth/act-as` · `error_code: E-AUTH-005` · `doctor exits: 1`

## What you're seeing

`/status` answered, but the POST to `<base>/doctor/act-as` threw instead of
returning a response.

## Why

The dev server died mid-run, or the `actAs` seam itself throws before it can
answer.

## The fix

Restart the dev server, and check `createVendo({ actAs })` (or the `auth`
preset providing it) for a construction-time error. Re-run
`npx vendo doctor`.
