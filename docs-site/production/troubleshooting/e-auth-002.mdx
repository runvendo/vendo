`check: auth/present` · `error_code: E-AUTH-002` · `doctor exits: 1`

## What you're seeing

`/status` answered, but the follow-up POST to `<base>/doctor/present` threw
instead of returning a response.

## Why

The dev server died mid-run, or a proxy in front of it blocks doctor's
routes.

## The fix

Restart the dev server, then re-run doctor.

```bash
npm run dev
npx vendo doctor
```

Verify `VENDO_BASE_URL` points at the running host origin, and remove any
proxy rule that blocks `/doctor/*` paths.
