`error_code: E-AUTH-006` · `status: retired`

## What you're seeing

Nothing: `npx vendo doctor` cannot print this code anymore. You are reading
it from an older run's output, or a saved report.

## Why

This code marked the `actAs` probe as skipped because your app was not
answering. Doctor reads files, so a stopped app blocks nothing.

## The fix

Nothing to do.
