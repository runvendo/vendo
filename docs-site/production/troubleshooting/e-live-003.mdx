```text live/venue
broken: /status returned an invalid execution venue
```

`check: live/venue` · `error_code: E-LIVE-003` · `doctor exits: 1`

## What you're seeing

`/status` answered, but the `blocks.sandbox` field it reported is not a
venue doctor recognizes.

## Why

Doctor accepts exactly three venue values, `e2b`, `cloud`, `custom`, plus
`false` for none configured. Anything else means the `/status` route is
patched, or the composition response is corrupted.

## The fix

Remove any custom `/status` handling in your route, then upgrade
`@vendoai/vendo` so the stock status route answers.

```bash
npm install vendoai@latest
```

Restart the dev server and re-run `npx vendo doctor`.
