```text auth/present
broken: present credentials did not reach the host API; set VENDO_BASE_URL
to the running host origin and restart the dev server
```

`check: auth/present` · `error_code: E-AUTH-001` · `doctor exits: 1`

## What you're seeing

Doctor posted a seeded cookie and bearer header to `<base>/doctor/present`,
and they did not come back through the wire's own same-origin fetch.

## Why

The wire does not trust the origin it is being probed on, so it strips
credentials instead of forwarding them. A 404 here instead of this message
points at a different problem: see the fix below.

## The fix

Set `VENDO_BASE_URL` to the running host origin.

```bash .env.local
VENDO_BASE_URL=http://localhost:3000
```

Restart the dev server and re-run `npx vendo doctor`.

If the probe answered 404 instead of this message, the composition likely
never declared itself `development: true` (or `NODE_ENV=development` was
never set), so the doctor-only routes never mounted. `next dev` sets that
flag for you; a plain `node` or `tsx` server needs it explicitly.
