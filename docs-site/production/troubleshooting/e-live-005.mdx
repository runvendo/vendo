`check: live/venue` · `error_code: E-LIVE-005` · `doctor exits: 0`

## What you're seeing

A warning: `/status` does not report a `blocks.sandbox` field at all.

## Why

This is version skew, not a broken install. The installed `@vendoai/vendo`
predates the `blocks.sandbox` field, so the venue check has nothing to read.

## The fix

Upgrade and restart.

```bash
npm install vendoai@latest
```

Restart the dev server, then re-run `npx vendo doctor`.
