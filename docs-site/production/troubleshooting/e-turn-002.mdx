```text turn/model
broken: live model turn cannot run; start the dev server at <base> and retry
```

`check: turn/model` · `error_code: E-TURN-002` · `doctor exits: 1`

## What you're seeing

This check never got to run at all.

## Why

It follows directly from a failed `/status` round trip. See
[E-LIVE-002](/production/troubleshooting/e-live-002) for why the dev server
was unreachable.

## The fix

Start the dev server at the probed base, then re-run `npx vendo doctor`.
