An embedded agent is not a loop and a prompt. To live inside your product it
has to know the product, know the user, act through your API, ask before it
does damage, draw real screens, and keep working after the tab closes. Vendo
ships that whole stack, and every block is composable and swappable — bring
your own Postgres, model key, sandbox, or agent loop.

## The stack

- **[Generated UI](/concepts/generated-ui)** — the agent renders real screens,
  views, and micro-apps in your brand, in a sandboxed surface. Every user owns
  their own copy, and can fork it or share it.

- **[The harness](/concepts/architecture)** — who thinks. Vendo's built-in
  turn runtime is the default; swap in Claude Code on a sandbox machine, or
  define your own.

- **[API tools](/connect/api-tools)** — your existing API becomes the agent's
  hands. Vendo sync extracts OpenAPI operations, tRPC procedures, server
  actions, and host routes into guarded tools that run as the signed-in user.

- **[Knowledge](/connect/knowledge)** — the agent answers how-it-works
  questions from your product docs, cites the passage it used, and says it
  does not know when the docs do not cover the question.

- **[User context](/connect/context)** — it knows who is signed in and sees
  what they are looking at, so "explain this charge" is answerable without a
  round of questions.

- **[Guard and approvals](/concepts/tools-and-safety)** — every call passes one
  policy choke point: risk labels, approvals, standing grants, breakers, and an
  audit trail.

- **[Automations](/deploy/scheduler-and-webhooks)** — pre-approved work runs
  while the user is away, on UTC schedules, host events, and verified external
  webhooks.

- **[Connected accounts](/capabilities/connected-accounts)** — each user
  connects their own Gmail, Slack, or GitHub once, brokered by Composio and
  isolated per principal. Vendo never holds the token.

- **[The MCP door](/capabilities/mcp)** — the same guarded tools served to
  Claude, ChatGPT, and Cursor over OAuth, acting as the person who signed in.
  Experimental.

- **[Persistence](/deploy/persistence)** — threads, apps, grants, audit, and
  secrets in one Postgres schema. Local dev runs the same schema on an embedded
  PGlite database, with nothing to configure.

- **[Theming](/connect/theming)** — set your tokens once in `.vendo/theme.json`
  and every shipped chrome surface renders on brand. Generation receives the
  same theme, so the screens the agent builds match the ones you built.

Whichever door you come in through — your own agent, Vendo's, or MCP — this is
the stack behind it. [Pick what you already have](/).
