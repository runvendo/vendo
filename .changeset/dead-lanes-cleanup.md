**The two dead product lanes are gone.** The cut island venue (native
`source:"generated"` component execution in the host page, and the
`componentTools` manifest nothing ever stamped) and the cut graduation /
per-app machine lane (`EditResult.graduated`/`.box`/`.pendingEgress`,
`AppDocument.egress`/`.egressApproved`/`.secrets`, the `{kind:"http"}` open
surface) are deleted outright — none of them had a live writer or producer.
Stored rows from those eras still read: the document schemas pass unknown
fields through, and the tree-node `source` enum keeps `"generated"`, so an
island-era tree still parses and renders inertly. The live storage seat for
remix/seed screens (`ComponentBundle`, `bundleOf`) and the `fn:` no-machine
error terminus are untouched.
