Close the mid-build window in the built-app sharing refusal. A row only declared itself a bundle when the build SEALED, so from the person's yes until the seal — minutes, and observed real builds ran 229–450 seconds — it carried neither signal `refuseBundleArtifact` reads, every one of the six refusal call sites let a share through, and the grant survived the seal into an app whose code then ran with the recipient's own permissions. The build now stamps `ui: "bundle"` when it STARTS rather than when it lands, so the row declares what it is becoming from the first moment a box can be spent and the refusal covers the whole window. Nothing else moves: the predicate is unchanged, the bundle route stays viewer-level, a failed first build still leaves the honest failure card, and normal screens — which carry `ui: "tree"` while their own build runs — stay shareable exactly as before.
