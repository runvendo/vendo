Built apps do not travel. A sealed bundle is arbitrary code whose only door is the guarded tool bridge, so a copy would run its author's code with the recipient's own permissions — that seam ships with its own consent story. One artifact-kind check, `refuseBundleArtifact`, now refuses `share`, `fork`, `exportApp` and `place` server-side, at the enforcer rather than in the client, with a `blocked` error naming the operation. Screens are untouched and stay shareable exactly as before.
