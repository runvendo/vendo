Brand values read from apps/demo-bank/src/app/globals.css and apps/demo-accounting/src/app/globals.css. Cadence sets numerals in Spline Sans Mono and reserves status colour for document state; Maple uses gain/loss colour on money.

Interactive: state pills, group carets, row selection and category dropdowns all work — no JavaScript.

Widen the vocabulary before narrowing the escape hatch

Across 52 measured apps containing an island (54 islands, 19 distinct asks, both hosts), the escape was almost never a demand for novel rendering. It was a demand for one of eight recurring answer-shapes the tree could not express — so the model left the format and hand-rolled the screen.

Each section below shows the proposed composite in both hosts' real brand styling, with the empty state it must own. Data is the demos' actual seed data.

Kit gaps the composites stand on

Six missing props on existing components. These are not answer-shapes; they are the substrate. Without the first one, ActionForm cannot exist at all.

Maplethe root cause — fields cannot name a tool argument
Field → argument binding
Today Form names a host tool on submit, but Input, Select, DatePicker and Textarea have no way to say which argument they fill. So a tree can render a form it can never submit — and every "let me do X" ask escaped to an island to close that gap in code.
Segmented single-choice controlhand-rolled 3×
Table subtotal / running-total columnhand-rolled 4×
Button pending / done / failed statehand-rolled 16×
Meter over-target tone and thresholdhand-rolled 7×
Card list selection and per-card actionhand-rolled 3×
Maplewhat a wired Button owns, once it has result states
All sixteen action islands re-invented this four-state sequence, each slightly differently — and three of them showed a success state for work that never happened.
Pending-approval is a fifth state unique to Vendo: the tool call is real, the guard is holding it, and the UI must say so without claiming the work is done.

Held at the approval gate

Approve it there and Maple sends it. Nothing has moved yet.

The island that stays

After all eight composites land, one class of island survives on the evidence — and it should. This is the differentiator, working as intended.

9 islands are genuinely custom 7 more keep a small custom core
Maple"create a component with a big Y" — 6 measured runs, correctly an island
The letter Y
No composite retires this and none should. Novel construction in the host's own brand is the capability no competitor has.
Cadence"can I afford to hire someone" — the residual core after AnswerBlock
What-if inputs
