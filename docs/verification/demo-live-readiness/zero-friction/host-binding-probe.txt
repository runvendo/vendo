Live host-binding matrix — prod builds, DEMO_AUTOLOGIN=1,
VENDO_BASE_URL=http://127.0.0.1:4300 (Maple) / :4301 (Cadence). 2026-07-26.
Only the exact configured authority may mint, and any X-Forwarded-Host
present must agree with Host after the same normalization.

On duplicate Host fields, Node keeps the FIRST and discards the rest --
the app cannot see the others, so it decides on the value it has. The
case that matters (an upstream hop routing on a different value) is
caught by the X-Forwarded-Host agreement check, which Railway's edge
always populates. See notes.md, "accepted residual".
